# FX Practice

自分専用の FX 検証アプリ（Forex Tester の代わり）。Mac mini 上でローカルに動かす。

## 目標

- **R1: 開いて 1 秒以内に、前回の続きから再開できる**
- **R2: MT4/MT5 の取引履歴を、ブローカーの実データどおりに再現する**（何もない所で決済されない）

## 時刻の扱い

- 内部の時刻はすべて UTC。表示と足の区切りのときだけ変換する（`src/core/time.ts`）。
- TitanFX のサーバー時刻は「ニューヨーク時間 + 7 時間」（実測: 2026-10-21 サーバー 08:43 / 日本 14:43 → UTC+3）。
  米国の夏時間・冬時間の切り替えはこのルールで自動的に反映される。
- 上位足はすべて 1 分足からサーバー時刻で区切って作る。日足は NY 17:00 で切り替わり、MT4 と一致する。

## 使い方（Mac mini M4）

```bash
git clone https://github.com/ryo224web/fx_practice_app.git
cd fx_practice_app
npm install
npm run dev     # ブラウザが開く
npm test        # 時刻変換と足の作成のテスト
```

## 進め方

1. ~~Node.js~~
2. ~~TitanFX のサーバー時刻の確認~~
3. ~~アプリの土台（チャート表示・時間足・表示時刻の切り替え）~~ ← 今ここ（仮データ）
4. Dukascopy のデータ取得・変換（主要通貨 + GOLD）
5. リプレイ再生と仮想の注文（買値線・スプレッド表示）
6. MT4 書き出しスクリプト + 取引履歴の再現（時刻のずれを自動判定）
7. 取引記録の保存と成績統計
8. （任意）他の PC からの利用（Tailscale）
